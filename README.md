## 👋 About

I design and ship **production systems** for clinics, pharmacies, and messaging infrastructure — from clean APIs and dashboards to Dockerized deploys behind Cloudflare.

**What you’ll usually find me doing**

- Architecting Angular + .NET + SQL stacks for hospital & pharmacy ERP
- Running self-hosted WhatsApp / SMS gateways (OpenWA) with dashboards & webhooks
- Hardening deploys: Nginx, named tunnels, health checks, and zero-drama rollouts
- Turning messy operational workflows into calm, automated products
